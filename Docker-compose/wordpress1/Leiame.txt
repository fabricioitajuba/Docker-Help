Esse compose é mais simples que o da pasta wordpress

- Para subir os containers pela primeira vez:
docker compose up -d

- Para parar os containers:
docker compose stop

- Para startar os containers:
docker compose start

- Para re-startar os containers:
docker compose restart

- Para parar os containers e deletar os volumes:
docker compose down -v

- Para saber quais container estão sendo executados:
docker ps -a
