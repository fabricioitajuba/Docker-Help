Para aumentar o tamanho do upload do php no wordpress:

$ docker ps 

Anote o id do container do wordpress

Verifique se o arquivo .htaccess possui a linha (ou parecida):
php_value upload_max_filesize 256M

Através do seguinte comando:
$ docker exec -it "id do container do wordpress" cat /var/www/html .htaccess

Caso não tenha, adicione a linha através do comando:
$ docker exec -it "id do container do wordpress" sed -i '$i\php_value upload_max_filesize 256M' .htaccess

se precisar alterar a linha:
php_value upload_max_filesize 256M

para:
php_value upload_max_filesize 512M

use o seguinte comando:
$ docker exec -it "id do container do wordpress" sed -i 's/php_value upload_max_filesize 256M/php_value upload_max_filesize 512M/g' .htaccess

ou então, altere manualmente:
Ex:
docker exec -it 92a2af66280b cat /var/www/html .htaccess
docker exec -it "id do container" sh
apt update
apt upgrade
apt install nano
nano /var/www/html .htaccess

mudar:
php_value upload_max_filesize 256M

para
php_value upload_max_filesize 512M

exit
docker compose restart

Verifique se a linha foi criada ou alterada:
$ docker exec -it "id do container do wordpress" cat /var/www/html .htaccess


## Tentativas mal sucedidas:

touch /usr/local/etc/php/conf.d/uploads.ini
echo "upload_max_filesize = 512M;" >> /usr/local/etc/php/conf.d/uploads.ini
echo "post_max_size = 512M;" >> /usr/local/etc/php/conf.d/uploads.ini
exit
docker compose restart

docker exec -it "id do container" cat /usr/local/etc/php/conf.d/uploads.ini


$ docker container exec -it "id do container" -c "echo 'php_value upload_max_filesize 512M' > '/var/www/html/.htaccess'"
Ex:
$ docker container exec -it 89f2dbbb8272 -c "echo 'php_value upload_max_filesize 512M' > '/var/www/html/.htaccess'"
